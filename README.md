Overview

This workflow integrates:

- Collect Earth Online (CEO) structured interpretation

- MODIS MOD13Q1 EVI time-series phenology

- Landsat seasonal composites (30 m)

- Multi-interpreter quality control procedures

The protocol produces reproducible crop-type and rotation labels using explicit phenology-based decision rules.
